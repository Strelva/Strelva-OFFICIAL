## Description (Full)

**OWSH A11y Check** is a free accessibility auditing tool that analyzes any webpage for WCAG 2.1 AA compliance issues — instantly, right from your browser.

### What It Checks

**Critical Issues**
• Missing alt text on images
• Color contrast failures (text readability)
• Form inputs without labels
• Missing document language
• Empty links and buttons

**Serious Issues**
• Heading hierarchy problems (skipped levels, multiple H1s)
• Generic link text ("click here", "read more")
• Missing skip navigation links
• Invisible focus indicators
• Icon buttons without labels

**Moderate Issues**
• Small touch targets (< 44px)
• Text smaller than 12px
• Missing landmark regions
• Tables without headers
• Auto-playing media

### Features

**Accessibility Score**
Get a clear 0-100 score with letter grade (A-F) showing overall page accessibility.

**Issue Breakdown**
See all issues organized by severity with:
- Element preview showing the problematic HTML
- WCAG criterion reference
- Plain-language explanation of why it matters
- Clear fix instructions

**Highlight on Page**
Click any issue to highlight the element directly on the page — no hunting through code.

**Elements Audit**
- Interactive elements (buttons, links, forms)
- Images with/without alt text
- Heading structure tree
- Landmark regions map
