# Chrome Web Store Assets

Place store listing assets here before submission.

## Screenshots

Folder: `chrome-extension/store-assets/screenshots/`
- 1 to 5 screenshots
- 1280x800 or 640x400 PNG

## Promo Assets (Optional)

Folder: `chrome-extension/store-assets/promos/`
- Small promo: 440x280 PNG
- Large promo: 920x680 PNG
- Marquee: 1400x560 PNG
