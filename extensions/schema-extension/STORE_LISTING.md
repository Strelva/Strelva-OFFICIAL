## Detailed Description

Instantly analyze any webpage's structured data (schema markup) and sitemap configuration with one click.

**What This Extension Does:**

Schema Analysis:
- Detects JSON-LD and Microdata markup
- Validates rich results eligibility for 14 Google schema types: LocalBusiness, Organization, Product, Article, BlogPosting, FAQPage, HowTo, Recipe, Event, JobPosting, Course, BreadcrumbList, WebSite, and VideoObject
- Scores each schema type 0-100 based on required (70%) and recommended (30%) field completeness
- Shows required and recommended fields with pass/fail checklist per type
- Displays key schema properties (name, rating, reviews, address, etc.)
- Shows raw JSON-LD code with copy-to-clipboard
- Validates @context and @type presence

Sitemap & Robots.txt Analysis:
- Checks /robots.txt, /sitemap.xml, and /sitemap_index.xml
- Shows robots.txt content with directive counts (disallow, allow, sitemap)
- Displays sample URLs from sitemap
- Reports sitemap type, URL count, and lastmod presence
- Identifies issues like missing sitemap references

**Why Use This Extension:**

- SEO professionals: Quick schema audits without leaving the page
- Developers: Verify structured data implementation
- Content creators: Check if schema is properly configured
- Site owners: Understand what search engines see

**Privacy First:**
- All analysis happens locally in your browser
- No data sent to external servers
- No tracking, no cookies, no account required
