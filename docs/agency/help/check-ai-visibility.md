# Run an AI visibility check

[Internal 1.0 draft](../README.md). You can check a public site before connecting it.

1. Open `/ai-visibility`. No signup is required.
2. Enter **Business name**, **Website**, **Business category**, and **City and state**.
   Only the name is required; include the website to measure website readiness.
3. Select **Run my AI audit**.
4. Read the readiness signals, citation-probe note and **Do this first**.
5. If a retained scorecard was created, use **Share scorecard** to share its
   public link. Use **Save a copy** when offered to keep a private workspace copy.

For a private assessment, open AI Visibility in your workspace, select
**Check a business**, fill in the business details and select **Run assessment**.
It saves after completion. If saving is interrupted, use **Recover assessment**
before starting another run.

The check reads website readiness and, when available, one live Gemini answer.
It does not measure every AI system or prove future rankings. Keep **Not measured**,
partial results and unavailable probes visible when you share the result.
Running a check does not edit a site or turn on monitoring.
