# Check your book in a batch

[Internal 1.0 draft](../README.md). Start with a list of client names and website URLs.

## At 1.0

1. Paste the URLs or upload a CSV, with up to 100 client URLs per batch.
   [NOT BUILT — tracked in #260]
2. Review the import dry run. Fix incorrect businesses before continuing.
   [NOT BUILT — tracked in #260]
3. Run the batch AI check. Review each result and its measurement status.
   [NOT BUILT — tracked in #260]
4. Use the portfolio's first-fix view to choose a client. Add that client from
   its result. [NOT BUILT — tracked in #259]

There is no batch check or CSV client-import screen in this revision. You can
[run one check at a time](./check-ai-visibility.md). Keep failed or unavailable
checks in your list; they are not low scores.

GoHighLevel import is also part of #260 and depends on external marketplace
access (#379). No connected account or import permission is assumed here.
