# Push an improvement to client Versions

[Internal 1.0 draft](../README.md). A Version adapts a source System for one client.
It is not a release or a copy of the client's whole business.

Before starting, you need a source with a newer revision and client Versions
linked to it. There is no general source-packaging or revision-publishing screen
in this revision. Do not expect **Review all** to create those records.
Ordinary delegated agency installation and updates depend on
[NOT BUILT — tracked in #325].

## Review existing Versions

1. Open your agency Home and select **Library**.
2. Read the source's latest **Revision** and each client's status.
3. Select **Review all** when there are **Improvement ready** Versions.
4. Read every result. **Prepared. Waiting on the owner's approval.** means
   prepared, not published. Conflicts and missing accounts are skipped.
5. For a conflict, compare **[Client] has** with **New default**. Use
   **Open [Client]** to open its workspace, then inspect the affected System.
   The current **Versions** panel shows context and lineage; it has no
   conflict-resolution controls.

Current Version management requires direct owner/admin membership in the target
business. These controls do not establish that an ordinary agency seat can update
a client. Do not grant admin membership as an onboarding workaround.

## Finish the 1.0 push

1. Prepare the client's update through your delegated agency access.
   [NOT BUILT — tracked in #325]
2. Have the owner review the exact improvement by email, even without an account.
   [NOT BUILT — tracked in #273]
3. For a website supported by Strelva's publication path, publish through the
   verified provider path after the required owner approval.
   [NOT BUILT — tracked in #263]
4. Read the resulting release or publication receipt. Check the actual live
   target before reporting a website improvement as live. Integrated Version
   publication receipts and their callers remain [NOT BUILT — tracked in #497].

A generic Version release records a definition snapshot. It does not prove that
a Wix, Squarespace or WordPress page changed. For those pages, use the existing
host's editor to make an authorized change; connecting the site does not add a
remote page editor.
