# Strelva Strategy — Index

> **What this folder is.** A divergent-exploration workspace for choosing Strelva's
> product and go-to-market direction going into Q4 2026. Twelve non-consensus approaches
> were written independently, then synthesized into a ranked recommendation. **The product
> direction is intentionally undecided** — these are options to choose from, not a settled
> plan. A complete redesign of the marketing/product surface follows once a direction is
> picked.

## Start here

→ **[`SYNTHESIS.md`](./SYNTHESIS.md)** — the cross-approach synthesis. Plots the 12
approaches on the axes that matter for a 2-person organic studio, clusters them, names the
strongest bets, the through-lines, the ones to discard, three ways to combine them into one
v1, and redesign directions for the top bets. Ends with an opinionated recommendation.

**TL;DR recommendation:** Run *Combination A* — focus on one Buffalo trade cluster; acquire
with the answer-native (AEO) audit as a proof artifact; deliver the free site + forwardable
weekly receipt as the wedge; compound the within-vertical benchmark as density grows; expand
each trusting client into the governed Business OS bundle. Ship the receipt and wire the
AI-Visibility audit category first — both are this-week moves on existing assets.

### The 12 approaches (`approaches/`)

| # | File | One-liner |
| --- | --- | --- |
| 01 | [`01-vertical-monopoly.md`](./approaches/01-vertical-monopoly.md) | Own one Buffalo trade cluster end-to-end (site + voice + content agent + one workflow) until within-vertical referral density and benchmark data make Strelva un-removable. |
| 02 | [`02-workflow-template-product.md`](./approaches/02-workflow-template-product.md) | Ship a public catalog of four named, fixed-scope SMB workflow products built near-instantly from a hardened template + thin config, governed by the existing auto/review/block engine. |
| 03 | [`03-agent-native-operations.md`](./approaches/03-agent-native-operations.md) | Sell one thing: a governed AI operations employee that runs the recurring parts of a business, with a named Buffalo human as approver of record. |
| 04 | [`04-proof-led-organic-engine.md`](./approaches/04-proof-led-organic-engine.md) | Stop marketing; ship proof artifacts (live audit, before/after scorecard, forwardable receipt) engineered so every client output is also a distribution asset. |
| 05 | [`05-buffalo-land-grab.md`](./approaches/05-buffalo-land-grab.md) | Become the single named studio owning the web + workflow layer for every 1–20 person WNY business, using a geo-locked cross-tenant benchmark as the moat. |
| 06 | [`06-operator-os.md`](./approaches/06-operator-os.md) | Sell the leverage not the labor: perfect the control plane that lets one operator run N clients, then license it to other solo operators as B2B2C rails. |
| 07 | [`07-interop-standard.md`](./approaches/07-interop-standard.md) | Become the open "Storefront Protocol" standard connecting a business's site, data, and the AI agents reading it — owning the `/api/v1` contract + capability manifest as a published spec. |
| 08 | [`08-aeo-ai-answer-native.md`](./approaches/08-aeo-ai-answer-native.md) | Engineer local businesses to be cited and booked by AI assistants — making "are you legible to ChatGPT?" the one score every Buffalo owner wants to fix, scored on the live site Strelva operates. |
| 09 | [`09-network-marketplace.md`](./approaches/09-network-marketplace.md) | Run Strelva as a local data co-op: every client joins a cross-tenant benchmark network answering "how do I compare to businesses like me, in Buffalo?" |
| 10 | [`10-education-community-pull.md`](./approaches/10-education-community-pull.md) | Build the book of business by teaching Buffalo owners how their web presence and operations work — free curriculum, in-person cohort, operator community — so the audience becomes the funnel. |
| 11 | [`11-business-os-bundle.md`](./approaches/11-business-os-bundle.md) | One subscription = a business's OS: Noah's free site is the front-door wedge, Jacob's one governed back-office workflow is the expansion, one spine and one receipt power both. |
| 12 | [`12-benchmark-data-asset.md`](./approaches/12-benchmark-data-asset.md) | Treat the cross-tenant dataset — not the sites or software — as the flagship: a public WNY Local-Business Performance Index that pulls owners in via "where do I rank?" |
